# deltaphoto

An accessible before-and-after image comparison component for React.

```bash
npm install deltaphoto
```

```tsx
import { Deltaphoto } from "deltaphoto";
import "deltaphoto/styles.css";

<Deltaphoto before="/before.jpg" after="/after.jpg" />;
```

Read the [documentation](https://dannyohana.com/deltaphoto) or visit the [GitHub repository](https://github.com/ohana23/deltaphoto).
